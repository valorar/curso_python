# Python para los que aprenden haciendo

Metodología *learning by doing*.

Un curso para aprender a programar en **Python** resolviendo ejercicios llamados **Retos**, organizados por niveles de dificultad progresiva. Está pensado para quienes empiezan desde cero.

## Aprender haciendo

La idea es aprender a través de la práctica: leer cada reto, escribir una solución, ejecutar el código y comprobar los resultados. Equivocarse, probar y corregir forma parte del aprendizaje.

Los retos permiten descubrir nuevos conceptos y practicar lo aprendido antes de avanzar al siguiente nivel.

## Retos por niveles

- Cada nivel reúne retos con una dificultad gradual.
- Los enunciados presentan el problema y ejemplos del resultado esperado.
- En los ejercicios de **código roto**, el objetivo es encontrar y corregir los errores del código proporcionado.

## Cómo trabajaremos

Usaremos **Google Colab**, que permite trabajar online desde el navegador con archivos **Jupyter Notebook** (`.ipynb`), sin instalar Python en el ordenador.

Cada notebook combina:

- **Celdas de texto**, con enunciados y explicaciones escritos en **Markdown**, un lenguaje de marcas para dar formato al texto.
- **Celdas de código Python**, que se ejecutan en el propio cuaderno para probar las soluciones y ver los resultados.
